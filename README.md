# 미로찾기 (Maze)

키보드 방향키로 조작하는 미로찾기 게임. 라이브러리 없이 HTML 파일 하나로 동작합니다.

## 플레이

[maze.html](maze.html) 파일을 브라우저로 열면 바로 시작됩니다.

## 조작

- `↑` `↓` `←` `→` 방향키 또는 `W` `A` `S` `D`
- 터치 화면에서는 도면 위를 쓸어서 이동

## 기능

- 판마다 새로 생성되는 미로 (재귀적 백트래킹 알고리즘 — 항상 해답이 존재)
- 왼쪽 위에서 출발해 오른쪽 아래 도착점까지
- 레벨이 오를수록 격자 확대 (레벨 1은 10×10, 이후 한 변마다 +2)
- 시간·걸음 수 기록, 지나온 칸은 자취로 표시
- 힌트 버튼: 최단 경로(BFS)를 1.4초 동안 표시하고 기록 시간에 +3초

## 구현

- 순수 HTML / CSS / JavaScript, 외부 의존성 없음
- 미로 렌더링은 Canvas 2D, 화면 크기와 devicePixelRatio에 맞춰 다시 그림
